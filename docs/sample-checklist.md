# 测试样本组织清单

下面是工程建议，数量需通过试点方差、成本和人工一致性校准，不能把示例规模当成统计充分性保证。

## 每个概念需要的资产

| 部分 | 请组织的内容 | 用途 |
|---|---|---|
| 概念卡 | ID、主体/风格类型、触发词、自然语言描述、必须保持/允许改变的属性 | 明确“生效”的语义，避免只看相似度 |
| 训练参考 | 原图摘要、数据 release、亲缘组、训练/开发划分、许可 | 检查拟合和训练记忆 |
| 独立留出参考 | 未参与训练、caption 改写或阈值调参的图；保留来源/亲缘组 | 检查泛化，防近重复泄漏 |
| 训练条件 | 底模/LoRA 完整 revision 或 SHA、rank/alpha/目标层、优化器/学习率、步数、唯一图片数、样本次、训练种子 | 数据版本之间的预算可比性 |
| 提示及约束 | 实际 prompt、去触发词后供 CLIP 使用的语义文本、必须/禁止出现的要素、能力标签 | 不把触发词直接送入 CLIP 解释 |
| 人工金标 | 盲评概念成功、属性/关系成功、风格、复制嫌疑、失败类型和不确定 | 校准代理指标，不自动造二元标签 |

## 提示矩阵

| 类型 | 建议样本 | 主要暴露的问题 |
|---|---|---|
| train | 接近训练描述 | 学会还是记住，训练图复制 |
| trigger | 只含概念描述符 | 触发能力、默认外观 |
| alter | 新动作、视角、背景、光照、数量、空间关系 | 内容泛化与提示遵从 |
| style | 同概念换摄影/水彩/素描等风格 | 风格迁移、训练风格锁死 |
| agnostic-class | 无触发词但同类名 | 概念泄漏到同类其他对象 |
| agnostic | 无触发词且无同类名 | 底模无关能力退化 |
| 组合扩展 | 两概念、概念+新属性、多个 LoRA 或跨底模 | 绑定/干扰；本版任务标签可扩展，生成适配器待实现 |

每条提示使用相同的多 seed 集合，base/LoRA 逐项配对。建议先用少量概念和每提示 4 个 seed 做功能试点，再按概念层面的变异估计正式规模；这不构成正式验收样本量。至少两个 seed 才计算 Vendi。只有一张触发词成功图无法检验多样性、泄漏、泛化或底模退化。

## 实验设计仍缺的部分

1. **目标架构和真实生成器**：当前已接入 FLUX.2-klein-9B 底模和标准 LoRA paired 文生图，支持 Kohya/Musubi 与 Diffusers A/B 格式；其他 LyCORIS 算法、架构和多 LoRA 仍需后端适配，不能宣称任意 LoRA 通用加载。正式输入见[完整链路手册](full-pipeline.md)。
2. **Base/LoRA 消融**：保持 prompt、seed、scheduler、steps、CFG、尺寸、负提示、精度及引擎版本一致；另行设计 LoRA 关/开、无触发词/有触发词、多个倍率，避免概念本来就在底模中。
3. **数据效果隔离**：相同底模、训练 recipe 与预算，只改数据版本；区分唯一图片数和样本次，最终测试集锁定。多训练 seed 的成本与误差需单列。
4. **泄漏筛查**：本版校验字节和已知 group；感知近重复、裁剪亲缘和内容泄漏需要外部候选与人工确认。
5. **人工校准与统计**：开发集定阈值，锁定测试集；按概念宏平均并保留细分类、配对差值和概念级区间。当前报告无置信区间、显著性或自动 pass/fail。
6. **风格与身份专项**：风格参考 Gram 距离已计算；身份/局部属性、文字/关系遵从的专项 evaluator 与人工校准待接。只要语义向量相似不能算全部通过。
7. **资源与可复现证据**：生成器回执、失败/重试、硬件、显存、推理时间、外部费用和软件锁定；当前 GPU 试点只测实际启用的编码器。

真实图片与参考正文放在仓库外，本仓库只保留 schema/生成逻辑和脱敏统计。正式测试集不参与数据补齐、提示改写调优或通过阈值选择。
